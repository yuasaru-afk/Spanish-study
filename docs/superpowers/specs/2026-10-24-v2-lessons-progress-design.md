# スペイン語学習アプリ 第2版：レッスンの区切り・単語集・やる気の仕組み 設計書

2026-10-24　初版（`2026-10-24-spanish-app-design.md`）を iPhone で使ったユーザーの要望から。初版の設計書・決まりはこの文書で変える所以外そのまま生きる。「（Claudeの判断）」はユーザー未確認。

## 1. 何のためか

ユーザーの要望（原文の趣旨）：
- 1ユニットの問題が多い。**1回あたり10問程度で切り上げたい**
- **学習記録やレベルアップでやる気を維持したい**
- **単語チェックは覚えてるか忘れてるかを選ばせて、学習に活かしたい**
- 基本は文法のレッスン。文法は**レッスンの最初に少し確認**し、**わからなければレッスン中に参照**する形でよい
- **たまに振り返りのレッスン**がほしい
- レッスンの**最後に単語チェック**。**単語集は別に起動でき**、レッスンの単語学習の記録と**つながっている**
- **文法だけ見たいときもそれで学習できる**ようにする

Duolingo で良かったもの：連続日数の炎、経験値、リーグの順位。**リーグはいらない。自分がレベルアップしていく仕組み**にする。

## 2. ゴール／やらないこと／失敗の形

**ゴール**：通勤の数駅で1レッスンが終わり、終わるたびに成長（XP・レベル・覚えた単語数）が見える。

**やらないこと**
- リーグ・他人との比較・架空のライバル
- ハートが減って続けられなくなるような罰
- 教材の練習問題を増やすこと（今回は既存の教材のまま。1ユニット＝1レッスン。将来増やすことは妨げない）
- サーバー・アカウント（記録は今まで通り端末内）

**失敗の形**
- 1レッスンが長く、途中でやめたくなる
- 単語チェックの結果が、単語集や復習に反映されない（別々の記録になる）
- レベルや XP が、学習と関係なく増える／減ってがっかりさせる

## 3. 決まったこと（ユーザーと合意）

### 3.1 レッスン（1ユニット＝1レッスン）
1. **文法の確認**：ユニットの要点を1画面で（3行前後の箇条書き＋例文1〜2つ、🔊付き）。初版の長い解説スライドはレッスンでは出さず、文法ノートで読む
2. **練習問題**：そのユニットの練習問題すべて（9〜10問）。わからなければ「📘 文法ノートで見る」→「クイズに戻る」（初版の通り）
3. **単語チェック**：最後に、そのユニットの単語のうち**まだ覚えていない語を最大8語**。カードで意味を見てから **「✗ 忘れてた」「○ 覚えてた」** を選ぶ。残りの単語は単語集に「新しい単語」として入る
- 途中で閉じても、次はレッスンの同じ所から（初版の通り）

### 3.2 振り返りレッスン
- 通常レッスンを**3回終えるごとに1回**、ホームに出す
- 中身は**前に間違えた問題**と**忘れてた単語**を中心に**10問程度**
- 振り返りで正解した問題は「間違えた問題」から外す

### 3.3 単語集（ホームから単独で開ける）
- レッスンの単語チェックと**同じ記録**を使う
- 学んだユニットの単語を一覧で見られ、状態（覚えた／あやしい／まだ）が分かる
- 「今日の復習」と「新しい単語を覚える」がここからできる

### 3.4 文法だけの学習
- 文法ノート（初版の通り、ユニットごとの解説）を単独で読める
- 読んだあとに、そのユニットの**確認問題を数問**解ける

### 3.5 やる気の仕組み
- **XP**：正解・単語チェック・レッスン完了でたまる。間違えても少しもらえる。減ることはない
- **レベル**：XP がたまると上がる。上がるほど次までの XP が少しずつ増える。上がったらお祝いの画面
- **節目のバッジ**：実力が分かる節目（覚えた単語数・連続日数・終えたユニット数など）
- **連続日数🔥**：今まで通り。ホームで目立たせる
- **学習記録の画面**：レベルと次までの XP、連続日数、カレンダー（やった日に色）、覚えた単語数、終えたユニット

## 4. Claude の判断（変えてよい）

- **XP の値**：正解 10／間違い 2／単語チェック 1語につき 2／レッスン完了 +20／振り返り完了 +30。文法ノートの確認問題は正解 5（同じ問題で何度も稼げないよう、1問につき1日1回まで）
- **レベル**：レベル n から n+1 に必要な XP ＝ 100 + 20×(n−1)。レベル1から始まる
- **バッジ**：単語 25／50／100／200語、連続 3／7／30日、ユニット 3／5／10完了、振り返り 1／5回。一度もらったら消えない
- **「覚えた」の定義**：単語の復習間隔が7日以上の段階（初版の LADDER で step 2 以上）。「あやしい」は step 0〜1、「まだ」は記録なしか新規
- **単語チェックの答えの使い方**：○覚えてた → 初版の good と同じ（1日後→3日後…と延びる）。✗忘れてた → again（今日の復習に入る）
- **フレーズと発音練習**：レッスン（10問）からは外す。フレーズは単語集に「フレーズ」の切り替えで入れ、発音練習（設定オン時）は単語集のフレーズから行う。初版の「レッスンの段」としては無くなる
- **文法の要点**：各ユニットの教材に要点（`points`：箇条書き3つ前後＋例文1〜2）を足す。Claude が書き、スペイン語は別エージェントで見直す
- **カレンダー**：直近5週間。日ごとの XP を記録して、その日に XP があれば色を付ける（多いほど濃く）
- **初版の記録からの引き継ぎ**：終えたユニット・単語の記録・連続日数はそのまま。XP は0から始める（過去の分は付けない）。練習段の途中だった再開位置は引き継ぐ。解説段の途中なら「文法の確認」から、単語・フレーズ・発音段の途中なら「単語チェック」から再開
- **やり直しの XP**：終えたユニットをやり直しても学習なので XP は入る。ただし練習問題の正解 XP は**1問につき1日1回まで**（文法ノートの確認問題と同じ決まり）。レッスン完了 +20、バッジのユニット完了数、振り返りの「3回ごと」の数え方は**初回完了のときだけ**
- **「覚えた」の基準**（上の定義を緩める）：○覚えてたを押した後、**別の日の復習でもう一度○**（step 1 以上）で「覚えた」。単語チェックで○を押しただけでは「あやしい」。最短で翌日に「覚えた」が増え始める
- **単語チェックの8語**：そのユニットの単語のうち、記録がまだ無い語から順に最大8語
- **間違えた問題の記録**：問題は「ユニットid:問題番号」で識別。間違えたら記録し、**どこで正解しても（通常レッスン・振り返り・確認問題）1回正解したら外す**。新しい順に最大50問まで
- **振り返りレッスンは任意**：ホームに出すが、次のユニットへの進行は止めない（初版のユニット開放の決まりのまま）。やらずに溜まっても出すのは1回分だけ。やった時点で「3回ごと」の数え直し
- **フレーズは記録なし**：単語集の「フレーズ」は見る・聞く・発音練習だけ。覚えた／忘れたの記録（cards）は単語だけ
- **単語集に出る範囲**：開いたことのあるユニット（着手済み・完了済み）の単語だけ。未開放のユニットの単語は出さない。「新しい単語を覚える」は、その範囲で記録がまだ無い語

## 5. 作り手に任せること

- 画面のレイアウト・お祝いの演出（初版の色・部品に合わせる）
- 振り返りレッスンの問題の選び方の細部（間違えた問題と忘れてた単語の配分、足りない時の埋め方）
- 単語集の並び順・絞り込み
- 記録データの持ち方（初版の `es-app-v1` を壊さず読めること）

## 6. 制約

- 初版の制約はそのまま（依存なし・圏外で動く・記録は端末内・カタカナなし・スペイン本国基本＋🌎）
