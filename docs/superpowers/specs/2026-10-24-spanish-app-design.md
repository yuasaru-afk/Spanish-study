# スペイン語学習アプリ（iPhone・通勤用）設計書

2026-10-24　壁打ちの結果をまとめたもの。「（Claudeの判断）」とあるものはユーザーと合意したものではなく、設計者側の判断。

## 1. 何のためのアプリか

- 使う人：ユーザー本人のみ。スペイン語はゼロからの初心者。日本語話者
- 学ぶもの：単語・文法・基本フレーズ
- **作る理由**：Duolingo を使ったが、文法的な解説がまったくないため「やっているのに身につかない」。このアプリは**なぜそうなるかを日本語で解説し、間違えたときに「なぜ違うか」まで示す**ことで、理屈で腑に落ちて身につくことを狙う
- 使う場面：通勤中が中心。片手・数分ずつ・途中で降りて中断・地下鉄で圏外もある
- ゴール：日常会話が一通りできる（Claudeの判断：CEFR A2 相当。単語800〜1,000語、文法は現在形・点過去・線過去・ir a＋不定詞の未来・よく使う命令形まで。全30〜40ユニット）
- 将来はビジネスで使いたいが、今回は対象外

## 2. ゴール／やらないこと／失敗の形

**ゴール**
- 毎日の通勤で開き続けられ、文法の理屈がわかった上で単語とフレーズが定着する

**やらないこと**
- ビジネススペイン語
- その場で AI に質問する機能（教材は事前に書いた固定のもの。AI 利用料・通信が要らない）
- App Store 配信（ユーザーの PC は Windows で、ネイティブアプリは作れない）
- 他人への配布・アカウント・サーバー側での記録保存

**失敗の形（動いても失敗とみなすもの）**
- 解説が薄く、Duolingo と同じく「当てて覚える」作りになること
- 圏外で動かない、中断すると最初からやり直しになるなど、通勤で使いにくいこと

## 3. 決まったこと（ユーザーと合意）

### 3.1 方言
- **スペイン本国を基本**にし、中南米で違う単語・言い回しは「🌎中南米では〜」と横に添える（例：ordenador／🌎computadora）
- vosotros と ustedes のような文法の違いも解説で触れる

### 3.2 作り方と置き場所
- **Web アプリをホーム画面に置く形（PWA）**。一度開けば圏外でも全部動く
- **GitHub Pages** に公開リポジトリとして置く。アカウントは `yuasaru-afk`（VS Code でサインイン済み、gh コマンドは未導入）。中身は教材のみで公開して問題ない
- 学習記録（進み具合・単語の復習予定）は **iPhone の中だけ**に保存し、外部に送らない

### 3.3 レッスンの流れ（モック確認済み）
モック：ホーム／解説／練習（間違えたとき）／単語カード／発音練習の5画面。ユーザーは「よい」と承認。

1. **ホーム**：一番上に「続きから」。今日の復習の数、ユニット一覧（済・今・未開放）、文法ノート・単語・設定への入口
2. **解説**：日本語で短く、なぜそうなるかを書く。例文はタップで読み上げ。日本語話者がつまずく点（名詞の男女、動詞の活用、ser/estar など）は特に丁寧に
3. **練習問題**：選択・並べ替え・穴埋め。**間違えたら正解だけでなく「なぜ違うか」を表示**し、選んだ答えだと意味がどう変わるかまで書く。文法ノートへのリンク付き
4. **単語カード**：スペイン語・性（男性/女性名詞）・日本語訳・🌎中南米の言い方。「忘れた／あやしい／覚えた」の3段階で、次に出す時期を変える間隔反復
5. **フレーズ**：場面別（自己紹介・レストラン・駅・買い物・道案内など）の決まり文句
6. **発音練習**：設定でオンにしたときだけ。お手本（ふつう・ゆっくり）を聞き、マイクで話すと聞き取れた文と判定を表示。「今は声を出せない→スキップ」あり
- 途中で閉じても、次に開いたら続きから再開
- **文法ノート**：解説だけを後から辞書のように引き直せる

### 3.4 読み方の示し方
- **カタカナ読みは付けない**。読み方は 🔊 の読み上げを耳で聞いて覚える。そのため例文・単語・フレーズには必ず読み上げボタンを付ける（発音のコツを日本語で一言添えるのは可）

### 3.5 設定
- 文字サイズ（小・中・大・特大）
- ダークモード（自動／オン／オフ）
- 発音練習のオン・オフ
- 読み上げの速さ

### 3.6 最初の出来上がりの範囲
- **最初は10ユニット**（あいさつ〜現在形の基本）を作り、ユーザーが通勤で1〜2週間使ってから、解説の詳しさや問題の数を調整して残り20〜30ユニットを足す

## 4. Claude の判断（ユーザー未確認・変えてよい）

- 解説は日本語
- 最初の10ユニットの構成案：あいさつ／発音とつづりのきまり／名詞の男女と冠詞／ser／estar と ser の使い分け／-ar 動詞の現在形／数字／時刻と曜日／gustar（好き嫌い）／レストランで（フレーズ中心）。実際の並びと切り方は教材を書く段階で詰める
- 学習記録の消失対策として、設定に「記録を書き出し／読み込み」（ファイル）を付ける
- 読み上げは iPhone 内蔵の音声合成（Web Speech API の speechSynthesis、es-ES の声）。音声ファイルは持たない
- 発音判定は Safari の音声認識（webkitSpeechRecognition）。**これは通信が要る可能性が高い**ので、圏外では発音練習だけ使えない旨を表示する
- 色づかいはモック（オレンジ基調）を出発点に、作る段階で整える
- **教材の執筆は Claude**（壁打ちで「最初に Claude が書いて固定の教材として入れる」と合意済み）。ユーザーは初心者でスペイン語の正誤を確かめられないため、書いた後に別の目（別エージェント）で活用・性・アクセント記号・🌎の言い方を見直す工程を必ず入れる。例文はすべて自作し、外部教材から流用しない
- **誤答解説の粒度**：選択式は選択肢ごとに個別の「なぜ違うか」を書く。並べ替え・穴埋めは誤答を列挙できないので、その問題の文法ルールに沿った解説（＋よくある間違いが分かっているものは個別に）とする
- **ユニットの中身**：1ユニット＝解説→練習→そのユニットの単語（新出15〜25語）→フレーズ（場面に関わるユニットのみ）。単語カードはユニットに紐づき、復習はユニットをまたいで出題。10番目のユニットは「否定文と疑問文」を足す
- **記録の書き出し**：iPhone の共有シート（ファイルに保存・AirDrop など）で JSON を書き出し、ファイル選択で読み込む
- **発音練習が動かない場合**：最初の10ユニットに含めるが、iPhone のホーム画面アプリで音声認識が使えないと分かったら、「お手本を聞いて自分で言う（判定なし）」に切り替えて残す。機能ごとは消さない
- **公開の段取り**：GitHub のリポジトリ作成と Pages の有効化は、必要ならユーザーにブラウザで数クリックをお願いする。Claude からの git push が認証で通らない場合は、VS Code の「ソース管理」から押してもらう

## 5. 作り手に任せること

- 使う言語・ライブラリ（フレームワークなしの素の HTML/JS で足りるかを含む）
- 教材データの持ち方（JSON などで本文と分けて、ユニットを後から足しやすくすること）
- 間隔反復の具体的な間隔
- 問題の形式ごとの数、1ユニットの長さ（目安：通勤の1〜2駅で1区切り＝3〜5分）
- リポジトリ名・アプリ名
- テストの方法（iPhone 実機での確認はユーザーが行う）

## 6. 制約・注意

- ユーザーの PC は Windows（Mac なし）。iPhone 実機での確認はユーザーに頼む
- iPhone はローカルの HTML ファイルを開けないため、必ずネット上（GitHub Pages）に置いて確認する
- iPhone の Safari は、ホーム画面に追加していないサイトの保存データを一定期間で消すことがある。ホーム画面に追加して使う前提とし、初回にその手順を案内する画面を出す
- 教材の正確さ：スペイン語の例文・活用・中南米の言い方は誤りがないよう、書いた後に見直す工程を入れる
- 作業フォルダは `Desktop\Claude\020スペイン語学習`。アプリ本体はこの中で別の Git リポジトリとして管理し、GitHub に上げる
